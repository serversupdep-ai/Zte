# Unlocked and Leaked

Slides and the interactive XOR demo for the talk **"Unlocked and Leaked: four methods through a
locked Dell BIOS"** by Craig S. Blackie (MDSec) and Darren McDonald (AmberWolf), presented at
DC4420 and BSides Basingstoke.

## Viewing

Open `slides/start.html` in a browser and use the arrow keys, space, or `N` / `P` to navigate.
`F` toggles fullscreen, `T` cycles the colour palette, and `+` / `-` adjust zoom for the room.

The interactive XOR key-leak demo is on the "live XOR demo" slide, and a standalone copy is at
`artifacts/xor-demo.html`.
