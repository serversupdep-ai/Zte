STEP 4 :: GREP FOR THE SETTING

I have found it easiest to just grep for keywords such as IOMMU or DMA:

// the setting we care about
Prompt: "Control Iommu Pre-boot Behavior"  ·  VarStoreId: 0x1  ·  VarOffset: 0x975  ·  Size: 8 · Min: 0x0 · Max: 0x1
This name differs from how it appears in the BIOS UI. Dell have customised the front end, but "Control Iommu Pre-boot Behavior" is ultimately the setting we care about.
