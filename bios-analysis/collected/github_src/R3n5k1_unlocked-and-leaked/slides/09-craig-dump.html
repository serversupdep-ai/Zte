STEP 1 :: DUMP THE BIOS

You can dump the UEFI by reading the SPI flash chip directly with a hardware programmer, or using flashrom within Linux with the internal programmer.

// using the internal programmer
$ flashrom -p internal -r dump.bin --ifd -i bios
// RECOMMENDED XGecu T48 / T56, much quicker and more reliable. Clips directly onto the SPI chip, reads at full speed, consistent results every time.
// USE WITH CAUTION CH341A, cheap and widely available, but most boards push 5V on the data lines and can fry a 3.3V chip (do the 3.3V mod first). Reads also less reproducible, re-read and re-hash.
// WARNING Always take three dumps minimum, hash them and ensure they match. If the hashes don't match, you don't have a dump, you have noise.
