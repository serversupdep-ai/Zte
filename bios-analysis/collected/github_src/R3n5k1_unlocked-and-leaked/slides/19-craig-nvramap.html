NVRAMAP :: AUTOMATING THE HUNT

After the blog post, PN-Tester built a tool that automates the entire mapping process. Vendor-agnostic, works against most modern UEFI implementations. Pass it an EFI module and a firmware dump and it does everything we just did manually, in one shot.

  • MODE 1 EFI Settings → NVRAM
    Search by keyword, find where DMA / VT-d / IOMMU settings live in NVRAM
  • MODE 2 NVRAM → EFI Settings
    Reverse lookup, given a GUID and key, find what setting it controls
--modify Interactive write mode, select a setting, change its value, get a patched NVRAM file ready to flash back onto the chip.
