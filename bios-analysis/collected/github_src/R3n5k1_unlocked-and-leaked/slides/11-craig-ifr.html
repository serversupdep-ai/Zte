STEP 3 :: RUN IFREXTRACTOR

IFRExtractor parses the HII (Human Interface Infrastructure) package list stored in the PE32 binary and converts it into readable text. The output describes the entire BIOS menu structure: form IDs, variable offsets, and option conditions.
