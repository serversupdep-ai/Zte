THE PROBLEM :: BIOS PASSWORD

While there are now tools to achieve the DMA attack, little was mentioned about how to modify the UEFI configuration should there be a password preventing you from accessing the setting.

Just remove the password?

THE BADCAPS APPROACH: RISKY

Sites like badcaps.net let users paste BIOS dumps and have others patch them to remove the password. This often causes the UEFI to enter factory mode, no password, but you may need to re-enter service tag and device details.

Effective, but a reflash can change the firmware PCRs (0/1). Where the disk encryption is sealed to those, the next boot demands the recovery key. Modern Secure Boot systems seal to PCR 7 and 11 instead, which a password change doesn’t disturb, so it’s a risk to check, not a certainty.

8FC8_Patcher does the same thing, patches the BIOS dump to remove the password, but is purpose-built for affected Dell firmware. github.com/craigsblackie/8FC8_Patcher
