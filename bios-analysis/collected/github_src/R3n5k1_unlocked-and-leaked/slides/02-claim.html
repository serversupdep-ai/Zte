UNLOCKED & LEAKED // 02 · what Dell promises

WHAT A LOCKED DELL BIOS PROMISES

  • 01
    SETUP PASSWORD stops local users entering BIOS setup or changing boot order
  • 02
    SECURE BOOT only Microsoft-signed (or vendor-signed) bootloaders run
  • 03
    IOMMU PRE-BOOT DMA DMA from PCIe / Thunderbolt blocked before the OS takes over
  • 04
    SIGNED FIRMWARE only Dell-signed updates accepted; flash is "write-protected"
every one of these falls apart with a SOIC clip and a £40 programmer.
