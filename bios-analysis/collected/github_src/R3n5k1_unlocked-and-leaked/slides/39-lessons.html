WHAT TO TAKE HOME

  • The BIOS settings and the BIOS UI state are recorded separately. One is only an indication of the other.
  • Large parts of the flash chip can be modified, and the BIOS will fail open, prioritising availability.
  • BIOS passwords have never been difficult to bypass, Dell or otherwise. They are a deterrent, not a hard security control.
