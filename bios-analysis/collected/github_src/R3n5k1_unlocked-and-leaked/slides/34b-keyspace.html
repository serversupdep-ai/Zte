UNLOCKED & LEAKED // 31 · the keyspace

FEWER THAN 256 KEYS PER MACHINE

key = KDF( device_seed , GUID , plaintext[0] )

device_seed and GUID are fixed per machine. Only the first character changes.

The first byte is the seed. It is stored in the clear because the scheme needs it to pick the key, not by accident.
One first character, one key. At most 256 keys on the whole machine, and fewer in practice: printable characters only.
Same first letter, same key. Any two passwords that start with the same character are XORed with the identical key.
the keyspace isn’t the password. it’s the first letter.
