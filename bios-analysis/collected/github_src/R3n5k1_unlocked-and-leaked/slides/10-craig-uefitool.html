STEP 2 :: FIND THE SETUP MODULE IN UEFITOOL

  1. Open the BIOS dump in UEFITool. The firmware appears as a tree of firmware volumes, files, and sections.
  2. Platform configuration options are defined inside a module named Setup. Use Search → Text tab and search for Setup.
  3. This highlights a firmware file named Setup containing a PE32 image section, the compiled setup executable.
  4. Right-click the PE32 image section and choose Extract body. This exports the binary to disk.
