UNLOCKED & LEAKED // 32 · key reuse

THE JOURNAL LENDS YOU KEYS

Remember the DVAR store is an append-only journal: every password ever set is still on the chip. Recovering keys hands you the key for every record, not just the current password.

Same first letter means same key. So a fully leaked key from any record unlocks a target with the same first character, even one whose own record never leaked enough.

SET ONE YOURSELF

The target’s first character is in the clear. Set a password that starts with it, read the record back, and you hold the whole key.

TAKE ONE FROM HISTORY

A past password already in the journal that shares the first character, and was short enough to leak its full key, hands you the same key for free.

you don’t need the target’s key. you need any key with the same first letter.
