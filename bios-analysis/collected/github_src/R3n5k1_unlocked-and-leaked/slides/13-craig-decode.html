STEP 5 :: DECODE THE IFR FIELDS

We need to understand the following to determine where and how the configuration is stored:

VarStoreId: 0x1   VarOffset: 0x975   Flags: 0x10   Size: 8   Min: 0x0   Max: 0x1   Step: 0x0
VarStoreId
0x1

UEFI variables are grouped into stores. Store 1 is the main Setup config variable saved in NVRAM.

VarOffset
0x975

The byte we want is 0x975 bytes from the start of the Setup variable store.

Size
8 bits

The field is 1 byte wide inside the variable store.

Min / Max
0x0 / 0x1

Only two valid states, this is effectively a boolean flag.

Flags
0x10

Standard numeric / boolean question type. No special behaviour.

Step
0x0

No increment step, consistent with a toggle (0 or 1 only).
