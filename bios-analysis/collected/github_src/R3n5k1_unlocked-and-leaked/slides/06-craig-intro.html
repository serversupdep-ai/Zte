UNLOCKED & LEAKED // 06 · bug #1: the motivation

BUG #1 :: THE MOTIVATION

A video by Pierre-Nicolas Allard-Coutu showed how to achieve full DMA over PCIe using PCILeech on a fully protected Windows 11 machine with TPM-only BitLocker, without triggering a recovery key prompt.

THE ATTACK CHAIN

  1. Disable pre-boot DMA in the UEFI
  2. Disable Virtualisation Based Security using Safe Mode
  3. Corrupt the DMAR ACPI table, prevent IOMMU from functioning
  4. Kernel DMA Protection bypassed, PCILeech gets a shell as NT AUTHORITY\SYSTEM
step 1 requires access to the BIOS settings.
