DELLPWN :: THE TOOL

  • [rust] single static binary, Linux / macOS / Windows
  • [in] SPI dump (any size, auto-locates DVAR)
  • [out] recovered password · offset · key · uncertainty
  • [fast] 32MB dump scanned in <500ms; partial brute-force when needed
  • [modes] CLI or TUI, live triage of a fleet of dumps
  • [bonus] also handles the related HP scheme (SHA-1 hashes → hashcat)
