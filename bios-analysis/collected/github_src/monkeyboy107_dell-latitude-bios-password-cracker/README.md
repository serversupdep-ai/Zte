# How to use this tool
## Prerequisites
 * Have Dell CCTK installed on the computer
 * Have windows installed (the linux support for Dell CCTK wasn't sufficient.)
 * Have python 3 installed
## To crack
Run `dell-password-bruteforce.py`. It will try to brute force the password for your dell latitude and unlock it.


### Please note it will take a long time to crack the passowrd
I would like to note that checking the password takes about 1 second and if the password is 10 characters long it will take ~221356800 seconds or ~9.6 years

A much better tool is [BIOS Password Recovery for Laptops](https://bios-pw.org/) which I didn't know of when I started this project
