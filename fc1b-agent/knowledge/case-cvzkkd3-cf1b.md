# Case CVZKKD3-CF1B

The active case for this agent is a Dell Precision 3640 Tower locked with a BIOS password: service tag CVZKKD3 with the CF1B suffix, so the lock screen shows CVZKKD3-CF1B. The machine model was identified from Dell's public service tag lookup, and its Express Service Code is 28055585559. The device is not registered to an owner on Dell's site, so an ownership transfer may be needed for the official route.

Computed keygen candidates for CVZKKD3-CF1B (from dell_keygen48.py, validated 48/48 on public vectors): primary password b1GMyMy52zkqJN3s (firmware CF1B path, BF97 construction, executed-firmware proven for pre-gate firmware), and alternates 32xa002Jg6xsXbY9 (fnA-2A7B-legacy), JnGkZZ9ZRIRPBm3[ and JxNGZ3yqWP26p9G[ (E7A8 first and second). Type each at the lock screen followed by Ctrl+Enter+Enter; they are accepted when the machine runs pre-gate era firmware.

Route order for case CVZKKD3: step one, try the four computed candidates above. Step two, if the machine boots to an OS, boot a Linux live USB and run `sudo ./bin/dell_cf1b_master-linux -t CVZKKD3 -f CF1B` as root; the machine's own EC returns the master code in the first 16 bytes of the type 6 GENERATE response — this is the definitive zero-hardware decryption for CF1B. Step three, if the machine does not boot, dump the full SPI flash with a CH341A programmer and run `python3 tools/dell_unlock_image.py --patch dump.bin` (or tools/dell_fc1b_unlock.py) to clear the 00FCAA and 00FDAA enrolled-record markers, flash back, and the board starts in Manufacturing Mode: write the service tag CVZKKD3, run the official BIOS update from F12 while still in Manufacturing Mode, then press Alt+F to exit. Step four, the official route: call Dell support with Express Service Code 28055585559 and proof of ownership.

Case research status: no offline keygen can exist for the CF1B family on latest firmware (proven by exhaustion: every public EC payload is AES-sealed), but the machine's own EC generates the master on request via the reversed type 6 session, which is what dell_cf1b_master uses. The full solution corpus (bios-analysis from the parallel session branch arena/01a087e2-zte) is integrated: 48-family keygen, EC session tools, firmware-execution harness, and the record-store-aware SPI patcher, all committed under tools/ in this workspace with the findings documents at dell-fw/findings/.
