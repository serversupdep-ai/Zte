# Dell FC1B master password

A Dell laptop locked with a BIOS password shows the service tag plus a four character suffix on the lock screen, formatted like `ABC1234-FC1B`. The FC1B suffix (also seen written as CF1B) identifies the newest Dell BIOS password family, which replaced the 8FC8 suffix on recent Dell commercial machines such as Latitude, OptiPlex, and Precision models from about 2023 onward. The suffix tells you which unlock route applies to the machine.

What the suffix means: FC1B (or CF1B) is the marker for the newest firmware-verified password family that replaced 8FC8 on recent machines; legacy suffixes like 595B or 1F66 mean the machine can be unlocked with a service tag keygen instead. FC1B does not mean the machine is permanently locked: the EC readout tool, the BIOS dump patch procedure, or Dell support all clear it.

The CF1B mechanism, fully reversed (2026-09): on the latest firmware, CF1B verification is a pure SHA-256 challenge against the enrolled value stored in the EC, and no offline keygen can exist for it — proven by exhaustion across every public EC payload (all AES-sealed; the transform lives only in the EC firmware and Dell's backend). On older pre-gate firmware (the 3090 equivalent is BIOS at or below 2.0.7), the password module still contains a legacy-construction fallback, so the computed BF97-construction master is accepted. The definitive zero-hardware recovery is the EC readout tool dell_cf1b_master, which asks the machine's own EC for the master code.

The EC readout route: boot a Linux live USB on the locked machine (works when only the setup or admin password is set and the OS still boots), then run `sudo ./dell_cf1b_master-linux -t SERVICETAG -f CF1B` as root on bare metal. The tool performs the reversed type 6 GENERATE session over the EC mailbox at ports 0x910 and 0x911: it sends the service tag and the family byte, and the EC returns 32 bytes; for CF1B the first 16 bytes are the master code, printed verbatim. The session is emulation-proven end-to-end against the real 2.27.0 vault module. A companion probe tool reads the SHA-256 challenge value R, and the grinder dell_cf1b_grind recovers weak or dictionary owner passwords by double SHA-256 search.

Older Dell suffixes are different: the legacy suffixes 595B, D35B, 2A7B, A95B, 1D3B, 1F5A, 1F66, 6FF1, BF97, and E7A8 do have known master password algorithms that compute the unlock code directly from the service tag. If the lock screen shows one of those suffixes, use the legacy Dell suffix master password generator route instead of the EC readout or the BIOS dump patch. See the legacy Dell suffix master password generator document.

For any CF1B machine the full route order is: first try the computed keygen candidates (they work on pre-gate firmware), then read the master from the machine's own EC with dell_cf1b_master, then patch the SPI dump with the manufacturing mode markers, then Dell support with proof of ownership. The firmware dump patch procedure document has the hardware route details.
